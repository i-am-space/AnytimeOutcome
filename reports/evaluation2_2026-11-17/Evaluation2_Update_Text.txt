Example: K=10, minimum prefix P=4
Four or more tokens are complete → a completion event authorizes a snapshot → send only its declared valid tokens → the target verifies while the
submitted tail finishes. This is an execution example, not a measured timeline.
Safety and limits
Epoch/context checks reject stale state. Rejection, cache misses, next-tree reuse and request-end barriers remain explicit. Full-request latency includes
final draining. There is no kernel preemption, and verification still computes a padded K+1 graph.

EXACTNESS IS AGAINST SHARED-FIXED16-V1 AR / ORIGINAL AR REMAINS DISTINCT
EVALUATION 2 UPDATE / 17 NOVEMBER 2026 / SHARED-FIXED16-V1

Why the original outputs differed
Single-query and batched execution used different numerical paths. BF16 rounding and
reduction-order differences can change nearly tied logits, flip the next greedy token, and
then change the rest of the response. The original implementation also exhibited
discrepancies.
What we changed
AR, SD and SSD use shared fixed-shape target arithmetic and batch-independent
attention. The shared AR reference is versioned explicitly. It can generate different words
from original AR; matching it does not repair historical-original-AR equivalence.

Component
Declared setup and meaning
Models and hardware
Qwen3-8B target / Qwen3-0.6B drafter. Two 48 GB L40S GPUs over PCIe across NUMA sockets; no NVLink. AR and SD use GPU0
only; SSD uses both GPUs.
Balanced workload
24 tuning prompts: 8 chat, 8 code, 8 document. Test split: 75 prompts, 25 per family. Three separate warmup prompts. Exclude the
three historically investigated test prompts.
Frozen inputs
Seed 0; exact saved input token IDs and chat template; complete inputs ≤2,048 tokens; model capacity 4,096. Models, tokenizer
and execution fingerprints recorded.
Output protocols
Primary: exactly 256 output tokens, ignoring EOS. Secondary: stop at natural EOS, cap 256. Secondary results reuse
fixed-output-selected settings.
Execution and timing
CUDA graphs and JIT miss fallback on; target and draft KV fractions 0.70. Three unscored warmups per fresh worker. Prefix caching
off. Timer includes prefills and final drain.
Statistics
Five rounds per method/protocol. Paired 95% confidence intervals: 10,000 seeded bootstrap samples over rounds and prompt IDs
within families.
Evidence: B1–B3. Batch size one means one user request at a time; K is draft depth, F is outcome-cache fan-out.
